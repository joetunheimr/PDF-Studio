# PDF-Studio

Alles-in-einem-PDF-App für Android: scannen, Ecken zuschneiden, Filter, Text & Unterschrift, PDFs zusammenfügen, Seiten drehen und löschen.

**Produkt-Homepage:** `index.html` im Projektordner. Quellen in `dev-app/` (Flutter + Kotlin/PDFBox), Build mit `dev-app/build_apk.sh`.
